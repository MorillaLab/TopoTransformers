# Jupyter Notebooks for Topological Lung Transplantation Analysis

This directory contains Jupyter notebooks demonstrating various aspects of the analysis.

## Notebooks

| Notebook | Description |
|----------|-------------|
| `01_data_exploration.ipynb` | Exploratory data analysis of patient cohort |
| `02_topological_analysis.ipynb` | Topological data analysis and feature extraction |
| `03_model_training.ipynb` | Model training and cross-validation |
| `04_interpretability.ipynb` | SHAP analysis and model interpretation |
| `05_example_model_usage.ipynb` | **Example: Loading and using the trained model** |

## Running the Notebooks

### Using Conda
```bash
conda activate topo-lung
jupyter notebook
