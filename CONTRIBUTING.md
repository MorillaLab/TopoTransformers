# Contributing to TopoAttention

Thank you for your interest in contributing! Here's how to get involved.

## 🐛 Reporting Bugs

Open a [GitHub Issue](https://github.com/MorillaLab/TopoAttention/issues) with:
- A clear title and description
- Steps to reproduce
- Expected vs. actual behaviour
- Your environment (OS, Python version, PyTorch version)

## 💡 Suggesting Features

Open an issue tagged `enhancement` describing the use case and why it would be valuable.

## 🔧 Submitting Code

1. Fork the repository and create a branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Make your changes. Follow existing code style (PEP 8).
3. Add or update tests if applicable.
4. Update the README or docstrings if your change affects usage.
5. Open a pull request against `main` with a clear description of what you changed and why.

## 📋 Code Style

- Python: [PEP 8](https://pep8.org/), formatted with `black`
- Notebooks: clear cell outputs before committing (`Cell > All Output > Clear`)
- Commit messages: imperative mood, e.g. `Add topological feature extractor`
